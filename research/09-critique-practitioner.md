# Design Critique 1: Skeptical Staff Engineer (2026-07-18)

16 failure modes, ranked. Full text preserved; act on ALL before/during build.

1. **The adapter IS the product and was a hand-wave.** Multi-turn session contract unspecified (auth, conversation IDs, SSE reassembly, retries). → Define hard interface now: `start_session/send_turn/end_session` → `{text, trace_id}`. Ship for ONE app. Position as "reference app + adapter SDK," not "any app."
2. **Replay + chaos need an interception point most apps lack** (in-process tool functions can't be stubbed externally). Vendors don't lack replay because it's whitespace — because it's invasive. → Precondition: tools routed through MCP/HTTP. Chaos → Tier 4, gated.
3. **Seeded ground truth needs an adapter contract**: `seed(case)/reset()/snapshot_state()`. Parallel cases pollute shared dev DB; side-effectful tools send real emails from adversarial cases. → Required capability for end-state layer; serial by default; Quorum-style throwaway isolation mandatory.
4. **Trace joining will produce flaky scores that look like model failures.** Batched async export (5s+), sampling drops, attribute truncation mid-JSON, partial traces (tool spans in flight). → Eval runs force sampling=always_on + flush-on-response; trace-completeness gate (expected span count or quiescence timeout); incomplete = INFRA_INCOMPLETE, never FAIL.
5. **No failure taxonomy / resumability.** → Per-case durable results, status ∈ {pass, fail, infra_error}; resume-from-manifest; bounded retries on infra_error only; infra_error excluded from denominators.
6. **Cost unbudgeted, two payers** (app tokens + judge tokens + Claude orchestration; optimize can be 50k–100k calls). → Cost estimated pre-run + reported post-run; default smoke (20 cases, k=1, deterministic only); hard budget stop in optimize.
7. **Judge-independence contradiction**: subagents pin only to Claude models; app may be Claude-powered → same-family generator+judge+optimizer (collapse + self-preference + judge-gaming). → Judge must be callable as a SCRIPT hitting an external non-Anthropic API when needed; otherwise document same-family bias and make human calibration mandatory. Do not ship the contradiction quietly.
8. **Statistical gate vs small n is self-defeating** (n=20–50 binary: McNemar significant only on huge effects → users re-roll candidates until one passes = garden of forking paths; Pareto pool = uncorrected multiple comparisons overfitting the frozen holdout). → Paired tests at n≥~100; Bayesian CI + decision threshold below that; holdout touch-budget with forced re-freeze after N looks; Pareto for pooling only, never keep/ship decisions.
9. **Dataset migration story missing** (tool rename → 200 stale cases, baselines incomparable, history resets on refactor). → `discover --diff` maps profile changes → affected cases, bulk-proposes migrations for review; baselines pinned to (dataset_version, profile_version, judge_version); name a maintenance owner.
10. **Discovery is confidently wrong for dynamic apps** (DB prompts, runtime tool registration, feature flags, per-tenant config). → Profile must be VALIDATED against live traces (observed tool/agent names match?) before generation is allowed; flag unverifiable surfaces.
11. **Generated labels least reliable where they matter most** (hard-negatives/OOS are ambiguous by nature; synthetic mislabeling pollutes routing F1 in the tail). → Mandatory human review of every hard-negative/OOS label; unreviewed cases quarantined from scored runs.
12. **Trace normalization treadmill.** Three conventions × ongoing spec churn = Langfuse's ingestion team rebuilt as a side feature. → Support ONE convention well (spec-current gen_ai.*), adapter declares it; others = contrib-quality with loud labels.
13. **Simulated users measure the simulator** without a shared world model. → Gate on seeded-environment capability; otherwise scripted multi-turn cases only.
14. **CI/headless + secrets + hooks.** → Headless entrypoint = plain script for deterministic layers (no Claude needed); env-var-only secrets, config schema rejects inline literals; smoke hook opt-in + async + debounced.
15. **Trust requires drill-down + continuous self-test.** → Every failed case links to a rendered trajectory (static HTML); known-good/known-bad canary cases inside EVERY scored run; judge TPR/TNR reported alongside every judged metric. Judge drift WILL move scores with zero app change — canaries catch it.
16. **Cut list (80/20)**: chaos → Tier 4 gated; simulated-user gated; red-team = document pointing promptfoo/DeepTeam at the adapter, don't integrate; Cartesian generation at scale premature pre-traffic; monitors experimental; DELETE panel-of-judges mode (own wave 2 refuted it); Invariant DSL = 20 lines of Python instead. Core that delivers most value: one adapter, deterministic layers, 30 human-reviewed cases, one calibrated judge, baseline diff with paired stats, human-in-loop reflection.
